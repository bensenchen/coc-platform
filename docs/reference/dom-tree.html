COC Platform — reference DOM tree

Semantic export for the responsive application shell; attributes are intentionally abbreviated to stable test hooks and accessibility names.

#root
└─ router
   ├─ /login → main[aria-label="Sign in"]
   │  └─ section → form → email input · password input · submit · magic-link button · Google button
   ├─ /home → div.home
   │  ├─ header → button[aria-label="COC home"] · settings · account menu
   │  └─ main → hero · workspace section → project section
   └─ /w/:workspaceSlug/p/:projectSlug[/page/:pageId] → div.app-shell
      ├─ aside → Home · workspace switcher · project switcher · nav
      │  └─ sections: Context · Data · Interface · Mgmt → page rows + actions
      ├─ separator[role="separator"]
      └─ main
         ├─ empty-project state, or
         └─ article.page
            ├─ header → page-kind label · h1
            └─ page renderer
               ├─ Context → toolbar · canvas · properties aside
               ├─ Data → table toolbar · table
               ├─ Interface List / ICD → planned renderer placeholder
               └─ Mgmt → sheet toolbar · format toolbar · table
